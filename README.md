👨‍💻 Sobre mí

Soy desarrollador Full Stack de Lima, Perú, enfocado en crear aplicaciones web modernas, interfaces responsivas, paneles administrativos y APIs REST.

Mi stack principal está construido alrededor de React, TypeScript, Node.js y PostgreSQL. Me interesa desarrollar soluciones mantenibles, con una buena experiencia de usuario, validaciones sólidas y una arquitectura organizada.
